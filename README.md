Sales Performance & Profitability Analysis

Project Overview

This project explores sales performance and profitability using Power BI. It focuses on regional performance, sales channels, shipping methods, and order returns.

The dashboard is designed to help users monitor key performance indicators (KPIs), compare business performance, and identify areas that may require further investigation.
